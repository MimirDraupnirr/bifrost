# Code de conduite

On est là pour faire un bon outil. Sois direct, sois courtois, critique le code et jamais la personne. Pas de harcèlement, pas de discrimination, pas de contenu hors sujet. Les mainteneurs peuvent modérer, fermer ou bannir sans débat quand c'est nécessaire. Pour signaler un comportement : un message privé à un mainteneur du dépôt.
